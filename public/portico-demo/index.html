Portico

Microsoft's Direct3D 9 tutorials from the DirectX SDK, compiled unchanged to WebAssembly. Their Direct3D 9 calls run on WebGL2, their Win32 window and message loop on this page.

This browser lacks WebAssembly JSPI, which the samples need: use Chrome or Edge 137+, Firefox 153+ or Safari 27+.

  • 1CreateDevice — a device and a cleared back buffer
  • 2Vertices — a vertex buffer of pre-transformed, colored vertices
  • 3Matrices — world, view and projection transforms
  • 4Lights — a material and a directional light
  • 5Textures — a texture loaded with D3DX and texture stages

Portico is the Direct3D 9 layer of a complete browser port of a Windows MMO client, described in this article. The library is private for now: if you would like to use it, write to Matteo.
